# 📊 Daily Updates | Work & Project Progress Tracker

### 🚀 Track Tasks • Monitor Progress • Manage Blockers • Stay Organized

A modern, responsive **React-based work tracking application** designed to simplify daily status reporting, project ticket management, progress monitoring, and team activity tracking.

**Daily Updates** provides a centralized interface for recording work activities, tracking ticket progress, managing blockers, and reviewing individual or team updates — all directly in your browser.

## 🔒 Data Storage & Privacy

**Daily Updates is a browser-local application, not a cloud-synchronized service.**

All records and account information are stored locally in the visitor's browser.

### What This Means

| Capability | Supported |
|---|---|
| Local browser data storage | ✅ Yes |
| CSV export | ✅ Yes |
| JSON backup and restore | ✅ Yes |
| Browser-only registration and login | ✅ Yes |
| Cross-device synchronization | ❌ No |
| Shared cloud database | ❌ No |
| Secure server-side authentication | ❌ No |
| Email password reset | ❌ No |
| SQL Server integration | ❌ No |

### ⚠️ Important Privacy Considerations

- Records are not automatically shared across users, devices, or browsers.
- Local login is a convenience feature, not secure access control.
- Anyone with access to the browser may be able to access stored records.
- Clearing browser storage can permanently remove local accounts and updates.
- There is no automatic cloud backup or account recovery.
- Avoid storing passwords, confidential company information, or sensitive project data in work updates.

**Recommendation:** Export JSON backups regularly, particularly before clearing browser data or changing devices.

## 💻 Getting Started

### Prerequisites

Before running the application locally, install:

- **Node.js 24**
- npm (included with Node.js)
- A modern web browser

### 1️⃣ Open the Project

From the repository root:

```bash
cd react-website
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start the Development Server

```bash
npm run dev
```

### 4️⃣ Open the Application

Open the local URL displayed in your terminal.

Vite commonly uses:

`http://localhost:5173/`

The exact port may differ depending on your environment.
