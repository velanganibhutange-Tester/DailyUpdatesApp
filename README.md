# Daily Updates App

Daily Updates includes the original ASP.NET application and a standalone React website with browser-only data.

## Open Website

[Open Daily Updates Website](https://velanganibhutange-tester.github.io/DailyUpdatesApp/)

This public GitHub Pages website can be opened by anyone in a browser, without running a local server. Local code changes appear on the public site only after a successful deployment.

For development on this computer: [Local Preview](http://127.0.0.1:5173/#home).

See the [website setup and GitHub Pages publishing guide](react-website/README.md) for instructions. Each visitor's records remain in their own browser; data is not shared between visitors.
